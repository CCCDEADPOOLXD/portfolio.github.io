Knuckle: Combat Architecture

The Challenge

Building a tight, responsive 3D fighting game required frame-perfect input buffering. If a player presses an attack button a few frames before their current animation finishes, the game needs to remember that input and execute it immediately on the next available frame.

The Technical Solution

To solve this, I architected a custom Finite State Machine (FSM) in C#. This allowed me to decouple the animation states from the core logic, creating a highly modular combat loop. The input buffer holds commands for a maximum of 10 frames, syncing seamlessly with the Unity Animator.
