Lethal Ludo: AI & Custom Pathfinding

Project Overview

Lethal Ludo is a fast-paced game jam project built under a strict deadline. Instead of relying on out-of-the-box engine solutions, I used this project as an opportunity to build custom AI logic and grid-based movement systems from scratch to power the core mechanics.

Technical Systems & AI

Custom A* Pathfinding Algorithm

Because traditional Unity NavMesh systems do not translate well to strict, grid-based board game logic, I wrote a custom A* pathfinding algorithm in C#. This system calculates the optimal route across the board by evaluating node costs and grid constraints, ensuring precise, predictable entity movement.

Rapid Game Jam Execution

Prototyping complex logic under a tight deadline requires extremely clean, modular code. I structured the pathfinding logic to be highly decoupled, allowing me to quickly iterate on the rules of the Ludo board without breaking the underlying movement mechanics.
