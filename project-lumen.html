Lumen: API Integration & Systems

🏆 IGDC 2025: Selected as one of the "Best Groups" to represent Artemesia College of Art and Design.

AI-Powered NPC Interactions

Lumen was a deep dive into systems engineering and API management. I served as the core gameplay programmer, handling 80% of the game's logic. The primary technical achievement was building a fully interactive NPC chat system from scratch.

Instead of relying on pre-written dialogue trees, I integrated Google's Gemini API directly into the game. By securely handling web requests, processing the JSON data, and feeding it into the UI in real-time, the NPCs can dynamically respond to the player based on predefined personality traits and narrative prompts, vastly enhancing player immersion.

Journal & Narrative Systems

Alongside the AI integration, I engineered the underlying systems that support the narrative, including a dynamic journal system that tracks player progress and updates real-time mission logs without frame-drops or memory leaks during serialization.
