Lumen: Systems & API Integration

🏆 IGDC Showcase - Best Group Award

Project Overview

Lumen is an award-winning project showcased at the India Game Developer Conference (IGDC). The core technical challenge was developing a robust, real-time pipeline to handle dynamic narrative generation, allowing the game to adapt its text and UI based on advanced backend logic.

Technical Systems & Pipeline

LLM API Integration

I spearheaded the backend architecture by directly integrating the Gemini API into Unity. I wrote asynchronous C# networking scripts to handle API requests and parse the JSON responses efficiently, ensuring the game maintained optimal frame rates without hitching during network calls.

Designer-Friendly Workflow Tools

Instead of hardcoding prompt logic, I built a modular pipeline tool for the narrative designers. This allowed non-technical team members to input data, adjust narrative weights, and seamlessly populate the dynamic in-game UI without needing to touch the underlying C# scripts.
