Lumen: API Integration & Systems

About The Game

LUMIN is a compelling 2D narrative prototype that casts you as Aquilo, a young man whose college commute turns into an impossible, decades-long journey. A mysterious cryo-disaster overtakes the world, forcing Aquilo into deep sleep only to awaken in a desolate, post-apocalyptic landscape that bears little resemblance to home.

The heart of LUMIN lies in its conversational mechanics. Progress is driven by engaging with the environment and its inhabitants to gather clues, uncover deep lore, and unlock mission objectives that directly impact Aquilo’s goal of saving the world.

Dynamic AI & API Integration

I served as the core gameplay programmer on this project, handling 80% of the game's logic. To support the core clue-gathering mechanics, I engineered a fully interactive, dynamic NPC chat system from scratch.

Instead of relying on pre-written dialogue trees, I integrated Google's Gemini API directly into the engine. By securely handling web requests, parsing JSON data, and feeding it into the UI in real-time, the NPCs can dynamically generate unique and unpredictable dialogue based on predefined personality traits. Every conversation is a potential clue, forcing players to actively extract critical historical information.

Journal & Mission Systems

Alongside the AI integration, I engineered the underlying logic that supports the narrative. This includes a dynamic journal system that tracks player progress, organizes gathered clues, and updates real-time mission logs without frame-drops or memory leaks during serialization.
