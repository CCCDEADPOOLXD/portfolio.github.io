LUMIN: API Integration & Systems

About The Game

Playing 1st time in Web might take time. LUMIN is a compelling 2D narrative prototype that casts you as Aquilo, a young man whose college commute turns into an impossible, decades-long journey. A mysterious cryo-disaster overtakes the world, forcing Aquilo into deep sleep only to awaken in a desolate, post-apocalyptic landscape that bears little resemblance to home.

Core Narrative and Mechanics

The heart of LUMIN lies in its conversational mechanics. The player must actively engage with the environment and its inhabitants to drive the story forward.

  • Dynamic AI Interaction: Converse with NPCs featuring AI-generated dialogue and voice implementation, ensuring that conversations are unique, responsive, and often unpredictable.
  • Clue Gathering: Every line of dialogue is a potential clue. Players must focus on extracting critical clues and historical information to piece together the events that destroyed civilization.
  • Mission System: Progress is driven by conversational outcomes. NPCs provide essential tasks that unlock new areas, reveal deep lore, and directly impact Aquilo’s core objective: saving the world.

Dynamic LLM Chat & Prompt System

To support these mechanics, I engineered a fully interactive NPC chat system from scratch by integrating Google's Gemini API directly into the game. This backend pipeline handles secure web requests, parses the JSON responses, and drives the real-time UI without stalling the main thread.
