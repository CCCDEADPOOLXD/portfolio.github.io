Asset Implementation & Optimization

Showcasing strict technical pipelines for 2D/3D asset integration, UI engineering, and memory management to bridge the gap between design vision and engine performance.

3D Asset & Animation Integration

The Goal

To establish a flawless pipeline from 3D modeling software into the Unity engine, ensuring diverse characters share scalable animation logic without visual tearing or lost weight data.

How It Works

I managed the full technical integration of 3D assets for the fighting game Knuckle.

  • Cross-Disciplinary Coordination: Collaborated directly with 3D artists to accurately import and implement complex rigged characters and custom models into the engine.
  • Animator Architecture: Translated raw animations into Unity's Animator graph using complex state machines and Blend Trees to easily swap distinct character models over shared combat logic.

Dynamic UI/UX Engineering

The Goal

To build responsive UI prefabs that automatically adapt to dynamic text volumes and aspect ratios, moving beyond static art placements.

How It Works

I worked closely with designers to translate mockups into robust engine systems.

  • World-Space Dynamic Chat (Lumin): Engineered resizable UI text bubbles that sit directly in the game world. These text boxes automatically scale to fit dynamically generated LLM input alongside interactive input fields and buttons.
  • Combat HUD Integration (Knuckle): Built the 2D combat UI to accurately read high-speed game states. The system tracks complex combat logic in real-time, ensuring health bars, combo meters, and character portraits scale flawlessly across diverse screen resolutions without stretching.

Texture Packing & Optimization

The Goal

To strictly manage VRAM memory footprints and minimize GPU draw calls for all 2D sprites and UI elements.

How It Works

I engineered a strict 2D asset pipeline utilizing Unity Sprite Atlases.

  • Sprite Atlas Generation: Configured the Scriptable Packer to automate the batching of disparate UI elements and 2D environmental props into unified texture sheets.
  • Compression & Padding: Actively managed tight-packing rules, edge padding, and compression formats to drastically reduce memory usage without compromising the art team's visual fidelity.

Performance Profiling

The Goal

To eliminate rendering bottlenecks in 3D environments, ensuring the engine only calculates what the player can actually see.

How It Works

I utilized Unity's built-in profiling and rendering tools to enforce strict asset budgets.

  • Geometric Optimization: Successfully reduced unoptimized raw geometry from over a million polygons down to just 159.0k tris and 263.1k verts.
  • Occlusion Culling & Frame Rate: Baked occlusion data to dynamically disable the rendering of hidden geometry. Combined with strict draw call batching, this maintained a steady 150.6 FPS while running at QHD (2560x1440) resolution.
