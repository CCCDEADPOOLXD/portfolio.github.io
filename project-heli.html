Project Heli: Cross-Platform Systems & Shaders

Project Overview

Project Heli is an asymmetric, 2-player co-op experience that bridges PC and mobile platforms. One player pilots a helicopter via PC, while the second player operates the weaponry and camera systems using an Android device. The environment features a dynamic, realistic battlefield where two AI factions fight in the background.

Technical Art & Systems

Thermal Vision & Post-Processing

To simulate the gunner's targeting system, I developed a custom full-screen Thermal Vision shader. This required rendering the scene data based on object temperatures/tags rather than standard albedo, and layering it with custom particle systems for dynamic smoke and explosions.

Mobile Gyroscope Integration

A core technical challenge was ensuring smooth and responsive controls across network latency. I engineered a system that captures raw gyroscope and accelerometer data from the Android device, filtering the inputs to provide precise, jitter-free weapon aiming on the PC server.
