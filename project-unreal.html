Unreal Engine Environment Design

Project Overview

This project was an exercise in high-fidelity environment composition and technical art inside Unreal Engine. The primary goal was to establish a strong visual narrative through environmental storytelling, utilizing advanced rendering features to push the visual quality to a cinematic level.

Technical Implementation

I focused heavily on the pipeline of scene assembly, material blending, and dynamic lighting. By leveraging Unreal's toolset, I was able to optimize asset placement, ensure cohesive color grading, and balance the light values to guide the viewer's eye through the composition naturally.
