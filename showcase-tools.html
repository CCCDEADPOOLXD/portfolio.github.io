Custom Editor Tools & Pipelines

A Technical Artist's job is to remove friction. These tools were engineered to empower designers to rapidly iterate on complex systems without needing to touch the underlying C# codebase.

Node-Based Combat Graph Pipeline

Hardcoding combo logic is a nightmare for iteration. To solve this, I engineered a highly modular, node-based graph editor inside Unity. This tool allows game designers to visually map out complex, stance-based attack sequences, branch combo paths, and adjust frame data purely through a drag-and-drop UI interface. It translates visual node connections directly into the game's underlying Finite State Machine, cutting down iteration time from hours to seconds.

🎮 See it in action: Knuckle

Dynamic LLM Chat & Prompt System

To create fully dynamic, AI-powered NPC behaviors, I built a robust pipeline to integrate Google's Gemini API directly into the engine. Instead of a hardcoded text box, I created a custom designer-facing tool where narrative designers can input system prompts, manage API keys, and define NPC personality weights. The backend system handles the asynchronous web requests, parses the JSON response data without stalling the main thread, and seamlessly dynamically populates the in-game UI.

🎮 See it in action: Lumen
